### Security

- Hive members ask for account slots on `slots.<swarm>.<hive>`, and a minted member credential may publish only its own hive's slot subject. The hub refuses and logs a take, heartbeat or release whose body names another hive. The antoncore `swarm-hive` user grants `slots.*.*` in place of `swarm.*.slots`. That shared password user serves every hive, so a holder of its password can still ask as any hive; the binding covers minted member credentials only.
