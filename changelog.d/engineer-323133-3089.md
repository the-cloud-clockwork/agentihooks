### Added

- Idempotent central session ingestion: a batch is checked against the caller's corpus and project grant before any write, committed in one durable SQLite transaction with stable event identities from session, source generation, sequence and byte range, replayed unchanged from any connection after a lost response with the current durable watermark, and refused whole when it mixes unauthorized projects; duplicates are counted in `ingest_duplicate_events_total` (SV2-SES-04).
