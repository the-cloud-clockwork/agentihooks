### Fixed

- The GitHub webhook receiver runs on the scoped bus when `hub.bus.scoped` is on, so its pull request, merge queue group and release events land on each tracking swarm's scoped events stream, which the review pass reads, instead of the root stream. It reads its `hub-github` repository index through an unscoped bus opened from the same config, because a scoped bus that does not provision refuses root state. The webhook NATS user needs publish grants on `swarm.*.events.<kind>` for its event kinds and stream info on each swarm's events and dead letter streams.
