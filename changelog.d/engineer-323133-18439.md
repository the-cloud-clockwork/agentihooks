### Fixed

- The thin task check reads a task's contract (must, check and judge), a proof label followed by at least three
  words and a done when sentence as its stated proof, so a task whose spec already says how it is proven is no longer
  held from engineers for a planner; only the under forty words rule still applies to it.

### Added

- `agentihooks swarm <slug> enhance sweep` reports the held count and releases each task held for enhancement that no
  freeze holds and whose thin task check now passes: it marks the enhancement skipped and scopes out the open
  enhancement plan task, written as the calling agent, so only a master or the operator can release; `--dry-run`
  lists the release candidates and writes nothing.
