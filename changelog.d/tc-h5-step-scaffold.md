`python -m scripts.tick.new_step <name> --group <group> --lane tick|slow --interval 60|120|600 --effects <ports> --feature <id> --module <steps module>` scaffolds a tick step: the step stub in its steps module, its budgets row, `tests/tick/steps/test_<name>.py` with the feature marker, the scenario index row and the feature map entry. It refuses a name any artefact holds and formats the Python it wrote; `--check <name>` reports which of the five artefacts exist. `scripts.tick.steps.MODULES` lists the step modules the registry loads before it is read, and a scaffolded module joins it.
