Review rounds and reader launches now live on the ledger task instead of each hive's local swarm home, so a successor seated on another hive spends the rounds its predecessor left, is refused a fourth round on the same pull request, and may open or mark ready a pull request whose standards and spec readers already ran. Each round adds its own stamp under a guard on the rounds it read, so two rounds started at once both count. Roll the ledger server to this release before its clients: an older server refuses the two new task fields, so swarm review fails and reader launches stay counted only on the machine that ran them until it rolls. While the ledger is unreachable but not yet marked offline, a reader launch waits for one failed task read, up to three attempts of ten seconds each, before it is allowed. A task already in review when the release lands starts its round counters again, because rounds counted in a machine's local files are not carried over.
