### Added

- `agentihooks ci lab flakes --out FOLDER [--hours N] [--objects ROOT]` copies the flake rows the lab stored in the last 168 hours, from a local objects folder or the lab object store named by the `CI_LAB_MINIO_*` settings, into `FOLDER/lab-flakes.jsonl` for the flake budget, which counts each flaky unit once however many exports reread it.
