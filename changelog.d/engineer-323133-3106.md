### Added

- Hives declare capabilities (`agentihooks hive set <id> capabilities=headed`), stored on the hive record and returned by `hive show` and the hive listing. Swarm tasks take `needs` (`ledger task add --needs headed`, `task set <id> needs=headed`): hive placement keeps only hives that declare every needed capability and otherwise waits with `the task needs a hive with headed, and no hive declares it`; local overflow and a local swarm refuse such a task unless the local hive declares the capability, and runtime placement keeps it off backends that cannot declare one.
- `swarm status` prints each agent's hive in a Hive column, and the ledger page agents table names each agent's hive under its name.
