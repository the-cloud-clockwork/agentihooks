A new lint step, "Hold the tick step pattern", runs `scripts.tick_pattern` against the base. It records each top level name in the tick module, each registered step missing a budget row, an interval from the set, a lane or a needs, reads, writes, effects or feature declaration, and each adapted implementation import outside the adapters, in the shrink only `tests/TICK_PATTERN_ALLOWLIST.json`. A pull request may not add an offence the base allowlist does not hold.
