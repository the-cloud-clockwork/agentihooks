### Changed

- The swarm tick pass no longer waits on GitHub, Langfuse or Grafana reads: CI speed, CI defects, CI flakes, Langfuse, Grafana and merge queue priority refreshes run in a detached job that scheduled ticks start for each swarm while their hive holds its lease, logging to `refresh-job.log`. The status publish reuses the pass's pull request view, and launches stop for the pass after twenty seconds.
