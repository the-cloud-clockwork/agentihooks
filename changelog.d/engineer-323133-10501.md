### Added

- The grader gate steps reference explains the protected gate step in the Tests lint job: it grades the pull request head against its merge base with the event base instead of the synthetic merge, so frozen changes already on dev are not blamed on a pull request behind dev, while a frozen file edit is still refused. It covers how to grade a pull request the same way by hand, the regression tests, feature map entry and Semgrep rule that guard it, limitations and troubleshooting.
