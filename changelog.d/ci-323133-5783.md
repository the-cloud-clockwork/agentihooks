### Fixed

- The pull request test planner lists every artifact page of a dev push run, up to two pages of 100, so a passed dev push run whose coverage shards are listed past the first 100 artifacts is the record again instead of an older dev run. Every candidate now reserves its second artifact page in the 100 request budget, so a search with no usable record covers 60 dev push runs instead of 70, and a run that fills both pages without its manifest and shards is named in the plan log.
- The mutation stats seed lists every artifact page of a pull request run, up to ten pages of 100, so a stats artifact listed past the first 100 artifacts still seeds the cache.
