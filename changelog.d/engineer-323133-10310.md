### Added

- The CI lab scheduler writes the files a test batch opened outside the dependency manifest, as its graded job's report lists them, into a note in the repository's manifest folder, and every stored manifest read merges the notes into the test records they name. The next test unit key of those tests then changes when one of the files changes, instead of reusing a verdict that never saw them, and a change to one of the files invalidates those tests in test selection.
