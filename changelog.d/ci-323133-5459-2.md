The ledger load gate also runs in the pull request tier. The Tests workflow's `select` job marks `ledger` as `run` when a pull request into `dev` changes `scripts/swarm_ledger/`, `tests/ledger_load/` or `.github/workflows/ledger-load.yml`; the `ledger-load` job then runs on that pull request and `Gate — Required` requires it to pass before the pull request can enter the merge queue. Other pull requests and the merge group skip it, and promotion still runs it on every `dev` push.
