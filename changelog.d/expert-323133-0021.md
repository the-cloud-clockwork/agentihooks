### Added

- The ledger API serves the task list of one focus target in pages: `GET focus/<target>/tasks`, or `agentihooks api get focus/<target>/tasks`, lists the tasks under the target that are not done through the cursor paging every collection uses, so a target one reply cannot hold is still read whole. `agentihooks api get focus/<target>` reads one target in one reply.

### Changed

- Past the reply limit the orders read, the focus list and the read of one focus target each name the command line read that fits, where the orders read named `focus/<item>` and the focus reads named the export.
