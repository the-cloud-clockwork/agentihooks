### Added

- Event hub: `agentihooks hub run` hosts the reactors declared in the hub registry. Each reactor is one durable consumer on the swarm event bus, skips an event whose entity version it already handled, and runs on one replica at a time when marked singleton, through a lease held by compare and set on the bus state store, as long as each singleton handler finishes within the lease time. A reactor that is not a singleton may handle two versions of one entity on two replicas at once.
- The `agentihooks-swarm` chart renders a hub Deployment with two replicas when `hub.enabled` is set. It is off by default; enable it with `hub.bus.url` once the NATS bus backend ships, because each replica on the memory backend holds its own bus.
