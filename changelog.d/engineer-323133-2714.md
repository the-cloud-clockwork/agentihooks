### Added

- Event hub: `agentihooks hub run` hosts the reactors declared in the hub registry. Each reactor is one durable consumer on the swarm event bus, skips an event whose entity version it already handled, and runs on one replica at a time when marked singleton, through a lease held by compare and set on the bus state store.
- The `agentihooks-swarm` chart renders a hub Deployment with two replicas when `hub.enabled` is set; `hub.bus.url` names the NATS address.
