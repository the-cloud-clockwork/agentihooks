### Changed

- The lint job runs its wall clock marker, dead code and mapped feature test
  scans at the same time in one step, `Run the wall clock, dead code and
  feature map scans together`, each from the protected grader exactly as the
  three separate steps did. The step prints each scan's log in its own group
  with the scan's seconds and names every failed scan in one error annotation.
  On six pull request runs before the change the three scans took a median
  67.5 seconds back to back while the slowest alone took 27.5 seconds.
