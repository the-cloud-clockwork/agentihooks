### Added

- The swarm knows a review lane and a `reviewer` agent kind, named `reviewer@<code>-<n>` with seats `review-<n>@<swarm>`. Lane templates carry a review cap, the `reviewer` profile and the `review` task kind; the swarm config gains `max_review`, zero on existing swarms and one on new template swarms; capacity, the tick and `ledger task add --lane review` take the lane. Review tasks use the review lane, and the review lane takes only review tasks.
