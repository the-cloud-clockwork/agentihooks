### Fixed

- The first read gate exempts a profile binding canary command only when its raw text holds nothing the shell would expand: only the characters `shlex.quote` leaves bare, spaces, single quoted segments and the `"'"` splice it writes. A command substitution hidden in a double quoted part of the canary script, a backtick, a process substitution, a glob, a tilde or an escape now gets the seat brief deny instead of running before seat brief. A Codex code mode canary is exempt only when the whole program is one exec command call whose object holds the command key alone. The real canary command stays exempt.
