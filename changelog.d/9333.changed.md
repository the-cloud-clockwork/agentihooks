Tick steps return their writes: the engine applies each one through its domain's compare and set applier, drops and reports a write whose guard moved, and the next pass recomputes it; the size pass and the grouping release are the first steps that write this way.
The fleet red notice returns its holds as writes too: its applier posts a hold only while the task is still open, unclaimed and on the same pull request, drops a hold a seat claimed mid pass, and forgets a refused notice so the next pass posts it again.
