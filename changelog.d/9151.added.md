Tick runtime and process adapters: the runtime port routes agent operations through the runtime router and lists herdr panes, and the processes port scans the process table once per pass. Each tick pass now gives every reaper target selection one shared process scan, rescanning only for a live process the snapshot lacks. Termination waits read each signalled process alone instead of scanning the whole table per poll; group membership is still read fresh once per termination. Every adapter operation refuses an expired deadline.
