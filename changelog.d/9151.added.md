Tick runtime and process adapters: the runtime port routes agent operations through the runtime router and lists herdr panes, and the processes port scans the process table once per pass. Each tick pass now gives every reaper target selection and termination one shared process scan, replacing it only when a live process the snapshot lacks is wanted. Termination waits read each signalled process alone instead of scanning the whole table per poll. Every adapter operation refuses an expired deadline before it calls out; forwarding a timeout into the runtime router and herdr is a follow up.
