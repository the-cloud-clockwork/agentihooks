### Fixed

- The shared command stripping that branch guard, prod lockdown, venv guard and the dependency banner use now finds heredocs in the tree-sitter bash parse instead of a regular expression. A `<<` shift in nested arithmetic, a `$[ ]` expression, an array subscript or a substring offset no longer opens a heredoc, so a guarded command on a later line is no longer hidden when a following line equals the shift operand. A `<<"EOF"` heredoc now strips like `<<'EOF'`. A heredoc whose terminator does not hold its delimiter word, or a command the parse reads with an error, keeps its heredoc text.
