### Changed

- The ledger op modules name the op context by one Protocol, `OpContext`: every function of a module registered in `ledger_core.EXTENSION_OPS` that takes the context is annotated against it, in place of an untyped, `Any` or `object` parameter. No op changes what it does. A Semgrep rule and a live check, `python -m scripts.feature_checks.op_context_typed`, hold the next op to the same type.
