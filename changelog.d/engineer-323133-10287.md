### Fixed

- The root hive service restarts itself on the new code when its checkout moves: after each beat `hive run` reads the checkout revision it loaded, and when a `dev` pull moved it, it says so on stderr and exits so the `agentihooks-hive` user service starts it again. Before, merged hive fixes ran nowhere until someone restarted the service by hand. The restart waits until no order worker is running, and a checkout revision unread at start restarts the hive once it reads.
