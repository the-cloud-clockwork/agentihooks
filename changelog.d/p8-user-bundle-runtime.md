Conditions, enforcements, lifecycle roots, workflows and classifier definitions read the user bundle between the root bundle and the profile chain, and the swarm overlay inventory lists the overlays of both bundles. `overlay new` and `overlay check` take `--dest root|user` and `overlay new` refuses to guess once a user bundle is linked; `bundle new --user` links a fresh bundle beside the root; the `user` condition scope is a destination only and still needs the operator's request.
