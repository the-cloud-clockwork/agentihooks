### Changed

- A pull request that changes only some jobs of the Tests workflow runs, among the tests that name or read the workflow, only the test definitions that index a changed job by name and those that read every job, instead of every such test file. A test that hands a workflow document on whole, or uses it other than by a constant key, reads every job, whether the document comes from a YAML load, a helper or a fixture, unless the test builds that mapping itself. An edit that changes the parsed workflow outside its jobs, or a workflow that does not parse on either side, still runs every workflow test, and an edit that changes no parsed job, such as a comment, runs only the tests that read every job, or the full suite when none does.
