### Changed

- The CI lab is now authoritative for the `lint`, `type-gate` and `test-count` gates on pull requests: `delivery.yaml` lists them under `lab.authoritative`, the Tests workflow skips those three jobs and `Gate — Required` reads the lab's check run for each. While the lab posts no check for one of them on pull request heads, `Gate — Required` fails every pull request once the 1200 second wait for the lab verdict ends. Set the repository variable `AGENTIHOOKS_LAB_OFF=true` to hand them back to Actions.
- A static gate's key carries the commit id context values it reads, and `scripts.feature_checks.lab_authority` refuses a lint, type-gate or test-count gate step that reads one its key does not carry.
