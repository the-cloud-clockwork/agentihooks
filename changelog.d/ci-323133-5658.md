### Fixed

- During panic, a fix branch session's `gh run rerun` is spared only when the head branch of the one run or job it names, read from GitHub in the checkout's origin repository, is that registered fix branch; a rerun of a dev run, of another branch's run, of an unreadable run, or naming no single run or job stays frozen.
- `agentihooks swarm <id> panic drop --fix URL` lets the master or the operator remove one registered fix from a swarm's panic without turning it off; the lab is told the fixes left.
