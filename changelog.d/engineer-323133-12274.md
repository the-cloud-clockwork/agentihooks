### Changed

- The status line and the Codex lifecycle hooks no longer start the OpenTelemetry worker and SDK to send the `agentihooks.tokens.fill_pct` and `agentihooks.tokens.burn_rate` gauges. They write the session's last fill and burn rate, with its agent name and resolved profile, into its presence seen record, and the hive daemon presence pass sends both gauges with the `session.id`, `agentihooks.correlation.agent.name` and `agentihooks.correlation.profile.resolved` attributes for tokens written in the last three minutes, only the fill when the burn rate is unknown. The other `agentihooks.correlation` attributes on these gauges resolve in the hive daemon process. The Redis token metrics write is unchanged. A host with no hive daemon sends no token gauges.
