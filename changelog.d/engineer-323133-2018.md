### Added

- `agentihooks swarm init --adopt` hands an existing shared ledger folder, its user and home to the bundle stack: ledger server start and stop go to the bundle `swarm` service, another shared folder is refused, and the stack Redis refuses `FLUSHALL` and `FLUSHDB`. `--no-start` writes the stack files and settings without starting a service. Documented in the Docker Compose quick start and the swarm command table.
