### Fixed

- The CI lab generates mutants without reading mutmut's config. The worker's trampolining and the scheduler's
  expansion used to load it from the process working directory, and the worker image's working directory holds
  nothing mutmut accepts, so every mutation unit raised before its sandbox started. Both now name the same mutants
  from any working directory and apply no `do_not_mutate_patterns`. The mutant generator takes the patterns as an
  argument and reads mutmut's config only without it, as the CI mutation gate does. The worker image smoke check
  trampolines a file from the image's own working directory.
