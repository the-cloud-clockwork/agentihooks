### Fixed

- The mutation stats seed asks GitHub again after waits of 5, 10 and 20 seconds when the pull request read, the Tests run listing or an artifact listing page fails, as it already did for artifact downloads, and prints each failed call with gh's error. One failed listing call no longer fails the dev push `mutation-stats-seed` job. A call that times out or is answered HTTP 404 is still made once, so a download answered 404 now fails at once instead of after 35 seconds of waits.
