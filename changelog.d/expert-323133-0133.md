### Fixed

- A CI lab worker fetches the test merge of a pull request head its node mirror does not hold yet. The scheduler's git bundle of that merge was prerequisite on the pushed head, so a worker that leased a unit before its mirror refreshed refused the bundle and the unit spent its one requeue. The bundle now excludes the merge's first parent only.
- A pull request grade started before the CI lab scheduler pod is replaced keeps its units. The new pod starts with an empty git store and answered every bundle request of that grade with 404, so all its units ended lost by the lab. The scheduler now fetches a graded commit its store lacks from the repositories it serves before it answers.
