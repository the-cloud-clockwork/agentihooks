### Fixed

- `agentihooks swarm <slug> merge priority <url>` moves the waiting merge queue entries ahead of the pull request at once, even while the head merge group's Tests run is in progress. It no longer stores a deferred record that the refresh replays only after that run ends, by which time GitHub had already started building the next waiting entry, so the pull request always missed the next merge group. Entries that are building stay in place, and deferred records stored before this release still replay or drop through the refresh.
