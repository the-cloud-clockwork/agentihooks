### Added

- A `recon` gate judges a swarm engineer's or CI agent's code edits and commits
  before the build gate: they pass only when `recon.md` in the task work folder
  holds the six recon headings in order, each with content, in at most 500
  lines. It ships at log only; `agentihooks swarm <slug> set recon-gate=deny` enforces it.
- The trace plan keeps a piece that only adds or registers regression tests and
  feature map entries for areas the task's `recon.md` names.
- Scouter launches made before the task's recon plan is valid no longer count
  against the sub agent budget.
