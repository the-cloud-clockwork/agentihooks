The night watch gate now defaults to deny: a swarm whose gates name no night watch mode now acts where it only logged before. It respawns its empty front door master seat at ten minutes, raises the `seat` alert for that episode, raises the `spawn` alert when ready work waits thirty minutes with no agent launched, raises the `merge` alert on a merge stall or three failing merge group runs, and emails the operator with each merge alert through the configured SMTP settings. Run `agentihooks swarm <id> set "nightwatch-gate=log only"` to keep the old behaviour on a swarm.
