### Changed

- Hook processes no longer start the OpenTelemetry worker and SDK on every event to send agent presence. Each hook event writes the session's seen record under the agentihooks home telemetry presence folder, and the hive daemon presence pass sends the `agentihooks.presence.agent` gauge for every session seen in the last three minutes, with the same attributes and the recorded seen seconds as its value. The pass removes records seen over a day ago and writes a beat file beside them. A host with no hive daemon beat in the last 30 seconds keeps sending the gauge from the hook, at most once a minute per session.
