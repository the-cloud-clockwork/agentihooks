### Fixed

Learned note scoping reads a per swarm set of seats with learned notes, written by `SeatMemory.learn`, instead of scanning the whole Redis keyspace on every call. The hub admission primed step had spent three to six seconds per admission on that scan over about 1.48 million keys, pushing lane admissions past the spoke ask timeout. The first lookup of a swarm, and the first after each hour, scans once to index notes written before the set existed or by a hive on an older release. One caller claims each scan for a minute and marks the index listed only after it adds the seats, so a failed scan is retried; other callers read the index meanwhile and can miss older unindexed notes for that one call.
