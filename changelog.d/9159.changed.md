Swarm modules no longer gain direct `gh` commands: the Semgrep rule `swarm-source-control-port` refuses a `["gh", ...]` command under `scripts/swarm` outside the files listed in `.semgrep/source-control-allowlist.json`, and the scan fails when that list grows against the caller base. `swarm park` reads whether a dependency pull request merged into dev, and `swarm publish` reads whether a predecessor pull request is settled, through the source control port and its sixty second deadline.
The `swarm-source-control-port` rule now also refuses the GitHub adapter's command builder, `scripts.tick.adapters.github.command`, outside the adapter; every swarm caller builds its `gh` command through it, so each file still doing so stays on the shrink only exception list until its calls move onto port tools. `swarm publish` reads a merged pull request branch and the panic button reads a fix branch through the source control port, whose change record now names the head branch. The feature map carries `swarm-tick-source-control-port`.
The source control port gains issue state, issue close and rate limit tools, answered by the GitHub adapter and the fake. Closing the issues a merged ready pull request settles and the GitHub rate limit sampler now go through the port, and the sampler leaves the source control exception list.
The source control port gains an issues enabled tool. `swarm park` reads whether the repository takes issues and posts its issue comment through the port, and the park module leaves the source control exception list.
The source control port gains latest runs and run cancel tools. The panic button and the panic tick list and cancel the fleet repositories' Actions runs through one port per repository, and the panic module leaves the source control exception list.
The source control port's change record now carries the pull request body and draft flag. Closing the issues a merged ready pull request names and the draft check in `swarm ready` read them through the port, and the linked issues and ready modules leave the source control exception list.
The source control port gains a merged at tool that reads when the change carrying a commit merged. The ledger host reads the newest dev commit's merge time through the port of the checkout's origin, and the ledger host module leaves the source control exception list.
The swarm health probes read the checks on a held pull request through the source control port checks tool and its twenty second deadline, and the health checks module leaves the source control exception list. The port checks tool now also returns the head commit statuses, so a required gate published as a status still counts.
The source control port gains an open changes tool that lists the open pull requests of a repository with each check in their rollup: its name, result and finished time. The fleet red hold and its notice pass list open pull requests through that tool and its sixty second deadline, and the fleet red module leaves the source control exception list.
The source control change record now names the head repository of a pull request, empty when that repository is gone. The swarm command line reads a pull request head branch and head repository through the port change tool and its twenty second deadline, and the command line module leaves the source control exception list.
