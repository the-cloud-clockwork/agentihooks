### Fixed

- A merge queue priority replay that dies between its dequeues and its restores no longer drops pull requests: each entry it takes out of the dev queue is recorded in Redis first, and the next tick queues back any recorded entry that is still open, unchanged and out of the queue. A priority for a draft pull request is refused before any entry leaves the queue, and a deferred priority whose target became a draft is dropped instead of replayed every tick.
