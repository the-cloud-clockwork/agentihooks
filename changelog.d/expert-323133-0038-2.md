### Changed

- A lab worker whose pod runs an image other than the one `CI_LAB_IMAGE` names restarts in place and keeps its pod, node and seat: the scheduler's lease API answers it `426` with no grant, and the worker stops leasing, drains within its termination grace and exits 0 so the kubelet restarts the container and pulls the floating tag; a pod pinned by digest is never stale. The worker entry point empties its work root at every start, so the venvs and caches a worker built there are built again after any container restart.
