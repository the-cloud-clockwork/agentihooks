### Fixed

- A CI lab grade diffs against the merge base of its head and its base. GitHub delivers a pull request's base with its head, and when dev moved on before the delivery that base is ahead of the fork point, so every static step that compares head with base read what dev gained since the fork as removed by the head, and the lab verdict differed from the Actions verdict on a head whose code was fine. The static units of a grade are now keyed on the files at the merge base and each job carries it as the base a worker checks out. The grader, the run key and the base a grade names stay the delivered base, a head whose base is its ancestor keeps its unit keys, and a head that shares no history with its base fails expansion.
