### Fixed

- The CI lab no longer grades pull request heads nobody wants any more. A pull request head now travels with a lane naming its head branch, so a newer head supersedes the older one; a closed pull request ends the work of its lane; and the first pass of a restarted scheduler retires every live pull request grade whose head is neither an open pull request head nor a plant branch head, from paged listings of its open pull requests and plant branches, read until two readings in a row agree. A closed pull request ends only the work that carries its base, so closing one of two pull requests from the same head branch leaves the other pull request's waiting head and any grade of its own base; a head graded only through the closed pull request loses its grade, as the known limits of the lab reference page state.
