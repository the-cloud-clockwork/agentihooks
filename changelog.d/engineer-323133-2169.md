### Changed

- The worker hive pod's memory request and limit follow its agent count:
  `workers.memoryPerAgentMi.request` (default 700) and `.limit` (default 2048)
  are multiplied by `workers.maxAgents`. One agent now requests 700Mi instead
  of 256Mi. Memory set under `workers.resources` is refused, and the chart
  proof checks the pod carries no node pin.
