### Added

- `agentihooks ci-lab-scheduler` runs the CI lab scheduler service; `--self-test` keeps the offline contract check.
- The scheduler reads its runtime config at `CI_LAB_RUNTIME_CONFIG`, serves `GET /capacity` and `GET /grades/<sha>` beside the lease API on port 8800 and `GET /metrics` on port 9108, both from a load built from the queue, the live grades, the slots workers offered on their lease polls and the day's core budget.
- The swarm image carries the locked `git` package the scheduler's mirror expander runs.
