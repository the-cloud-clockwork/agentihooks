### Security

- The `AGENTIHOOKS_NATS_SIGNER` record must live under the OpenBao path `agentihooks/hub/`, which only the hub role reads, because it holds the NATS system account credential. A signer path anywhere else, or one with an empty, `.` or `..` segment or a percent escape, is refused before OpenBao is read.
- `AGENTIHOOKS_NATS_TRUSTED_OPERATOR` names the operator public key the NATS server trusts, outside the signer record so a writer of that record cannot change it. `hive revoke` and `hive remove` refuse to push an account update whose issuer is not that key, because a NATS full resolver accepts an update signed by any operator from a system account user and such an update breaks the account.
