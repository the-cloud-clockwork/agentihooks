### Security

- The `AGENTIHOOKS_NATS_SIGNER` record must live under the OpenBao path `agentihooks/hub/`, which only the hub role reads, because it holds the NATS system account credential. A signer path anywhere else is refused before OpenBao is read.
- The signer record names the NATS server's trusted operator public key in `trusted_operator`. `hive revoke` and `hive remove` refuse to push an account update whose issuer is not that key, because a NATS full resolver accepts an update signed by any operator from a system account user and such an update breaks the account.
