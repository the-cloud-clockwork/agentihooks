### Added

- The swarm tick's `review pass` queues one review lane task for each pull request a swarm task opens, each merge queue group and each published release, keyed by the change so a repeated event adds nothing. It runs only on a running or drained swarm whose review cap is above zero, reads one durable consumer per event kind on the shared bus, and ignores events older than six hours.
- The hub GitHub webhook publishes `merge_group.requested` and `release.published` events to every swarm tracking a pull request in that repository, after the lab head, so a failed swarm publish answers 503 and GitHub redelivers. The webhook NATS user needs publish grants for both subjects.
