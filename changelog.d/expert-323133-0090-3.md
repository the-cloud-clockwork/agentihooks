### Fixed

- The CI lab scheduler grades only the repositories it serves: those `CI_LAB_SERVED_REPOSITORIES` lists, or else the one `CI_LAB_REPOSITORY` names. Intake ignores a new head of any other repository before it checks the actor, so that head starts no listing of the branches of a repository the lab holds no credential for and gets no failed check on its commits. Work the lab already stored for such a repository is not swept: each held head is dropped at its next start (#13759).
