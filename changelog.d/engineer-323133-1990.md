### Changed

- Every master launches named by its seat and swarm, `master 1 · <swarm>` for
  the front door and `master 2 · <swarm>` and on for backend masters: the
  Claude session name, the herdr tab and the Remote Control session all carry
  it. `init-agent --title` sets the display name and tab label apart from the
  agent name.
- With `AGENTIHOOKS_MASTER_CLAUDE_LOGIN` on, a front door master ordered on a
  subscription or API route launches on the master claude ai login instead,
  so it registers Remote Control; an API ordered front door then runs on the
  subscription login rather than the API key.
- `MASTER_INBOX_CLASSIFIER_WITH_FALLBACKS` is on by default, so related master
  inbox items reach one master; round robin stays the fallback, and `false`
  turns grouping off.
