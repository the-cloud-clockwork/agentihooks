`FencedRuntime.live_names` lists the live agent names once per tick pass. The listing lives on the pass's `PassProcesses`, so every fenced runtime of the pass shares it, and each read gets a copy. A fenced `spawn`, `collect`, `expire`, `retire`, `reap_name`, `close_space`, `close_pane` or `resume` drops it, even when the call fails, so the next read lists again. Outside a pass every call lists.
