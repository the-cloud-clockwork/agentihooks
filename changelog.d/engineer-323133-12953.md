### Added

- Swarm pr records a GitLab merge request on the task: it confirms the merge request through the GitLab API with the GitLab token and records the same branch, repository, number, head and link fields as for a GitHub pull request, and the stage and prerequisite scopes accept a GitLab merge request on the command line and in the ledger. A stage or prerequisite link must now be an exact change request link, so a pull number with a leading zero or a project name ending in .git is refused there.
