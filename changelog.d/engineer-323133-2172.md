### Fixed

- Hive placement matches the swarm repo by its origin, so a swarm whose repo is a local checkout path places engineers on a remote hive that lists the GitHub origin and its own pod path.
- A headless hive that refuses an agent for any reason, not only for lack of room, sends it to the UI hive with the headless reason recorded as the fallback, and an account a headless hive takes outright still wins over an earlier account only the UI hive takes.
- Every task the placement holds back is logged in the tick output as `task <id> waits: <reason>` instead of waiting silently.
