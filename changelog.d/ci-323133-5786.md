### Changed

- The CI lab grades the Tests workflow's `test-count` job with static units. The static executor supplies
  `runner.temp` as the unit's run folder, `github.event_name` as `pull_request` and each matrix value the gate's
  job holds at one value, so the lint gate that proves the mutation gate self plant is lab gradable too.
- `python -m scripts.ci_lab.static_gates --ci-only` lists the jobs whose verdict stays with Actions, with the
  reason: `docs` and `writer-lock`, and any job of a reusable workflow a static job calls that calls another
  workflow.

### Fixed

- Static gate discovery no longer raises `KeyError: 'steps'` on a job of a called workflow that calls another
  workflow; it grades the other jobs of that workflow.
