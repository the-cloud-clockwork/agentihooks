### Added

- Swarm tasks take a `workstation` flag (`ledger task add --workstation`, `task set <id> workstation=yes|no`) for work that reads or changes the workstation's primary checkout or its task folders. Hive placement refuses such a task on every remote hive with the wait line `the task needs the workstation, so no remote hive takes it`, keeps only the workstation's own hive entry as a candidate, and a hybrid controller then runs it on the local machine; runtime placement keeps it on the local backend.
