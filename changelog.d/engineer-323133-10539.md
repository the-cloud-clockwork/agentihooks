### Fixed

- The credential guard now judges the rest of a heredoc's delimiter line, so `cat <<EOF > out; cat .env` with a body is refused like a plain read of the file.
- The credential guard now checks a heredoc body as a command when a shell runs it, as in `cat <<EOF | bash` or `bash <<EOF`, through sudo or a kubectl, docker or ssh wrapper, so a credential read inside the body is refused.
