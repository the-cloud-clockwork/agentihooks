### Fixed

- The credential guard no longer reads a star glob as a process environment path. A shell case pattern holding a GitHub issues or pull request address with star globs, or a listing with star folders, passes. A path counts as a process environment read only when the segments after a segment matching proc are a process id then the file, a process id, task and thread id then the file, a process id followed by a cwd, root or fd link, or a segment that can expand to another depth. Every real process environment read stays refused.
