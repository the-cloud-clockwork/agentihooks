### Fixed

- The CI lab relay keeps running when the GitHub App refuses its push, check runs or pull requests token: the tick records the head held for a later pass, keeps it pending and holds that repository's relays for the scheduler's post hold, while the heads of other repositories still relay. A refused App token's message names the permissions it asked for and GitHub's answer, such as `GitHub App cannot supply scoped checks write credentials: GitHub answered 422`, so a refused checks token no longer reads as a contents write problem.
