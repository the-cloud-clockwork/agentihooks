### Changed

- A dev push that reuses the passed queue run of its commit runs one unit job, `unit (3.12, copy)`, instead of twenty unit legs. It restores every queue leg in one download, lays out the twenty push legs with the queue leg mapping, checks and summarizes each leg's coverage with the unit legs' own commands, and uploads each leg's durations, coverage, flakes and executed lines in the unit job's order, legs side by side, through the results service. Shard check, the pull request test plan's dev record search and the dispatch and coverage ratchet base lookups accept the copy job as a complete unit result. Every other run still runs all twenty legs.
