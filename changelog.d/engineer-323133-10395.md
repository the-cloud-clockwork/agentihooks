### Added

- The CI lab scheduler and relay fetch a head pushed only to the lab remote: their mirrors fall back to the lab remote `AGENTIHOOKS_LAB_REMOTE` names, with `AGENTIHOOKS_LAB_REMOTE_TOKEN` sent as the basic password of the user `lab`.

### Changed

- A lab grade of a head pushed to a `refs/grade/*` ref posts no GitHub check run and leaves its check runs to the relay.
- The relay's push token asks for workflows write as well as contents write, so a relayed branch that changes workflow files is accepted.
