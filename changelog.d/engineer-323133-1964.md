### Added

- `agentihooks swarm init NAME --plan FILE --repo DIR` is the one way to create
  a swarm: it brings the swarm stack up, then creates the swarm and its ledger
  under NAME inside the stack, paused, so the stack's ledger page serves it;
  running it again for the same swarm changes nothing.
  NAME is one or two lowercase words joined by a dash and ending in `swarm`; a
  missing, invalid or taken name is refused with the rule and two suggestions
  from the plan title.
- `agentihooks swarm names check NAME` says whether a name is valid and free,
  with suggestions. The init-swarm skill asks the operator for the name first.
- `SWARM_COMPOSE_PROJECT` in a swarm stack's `.env` names its Compose project,
  so a second stack home never touches the first.

### Changed

- `agentihooks ledger new --size swarm` and a typed `agentihooks swarm <id>
  create` are refused and name `swarm init`, except for proof and demo swarms
  named by code.
