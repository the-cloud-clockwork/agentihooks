### Fixed

- A release moves `agentihooks-worker:release` only when it is the newest published release. The release only `hive` job of the Swarm worker image workflow, which queues every release one at a time, now tags the worker release and reads the remote tags at move time: it moves the release tag unless a newer release already published its worker image, and pushes the release tag before the version tag. An older release whose image job finishes after a newer one no longer moves the tag back, and the image job no longer tags releases from the newest flag it read at checkout.
