### Fixed

- A release moves `agentihooks-worker:release` only when no newer release has already published its worker image. The hive job of the Swarm worker image workflow, which runs one release at a time, reads the remote tags when it moves the tag and pushes the release tag before the version tag, so an older release whose image job finishes after a newer one no longer moves the tag back.
- The worker image job no longer tags releases from the newest release flag it read at checkout.
