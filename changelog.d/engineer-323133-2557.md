### Changed

- Each agent launch is admitted by the measured headroom of the machine it lands on instead of fixed agent counts: a hive refuses once projected CPU or memory use passes 80 percent, and the workstation also keeps swarm agents to 40 percent of its CPU and memory. Pending launches hold their share of the host line for fifteen minutes, three five minute load windows, through atomic reservations, and masters keep their existing exemption from hive room. Swarm status and the Top bottleneck stat on the ledger count waiting launches by refusal reason (cpu, ram, quota, placement, node cap, missing telemetry); the node cap count stays at zero until the cluster side reports a refusal naming it. Admission costs each agent at the default memory per agent figure, so a changed memory per agent setting reaches the host pressure alert but not admission. The hive max agents and local max agents settings stay readable but no longer control launches.
