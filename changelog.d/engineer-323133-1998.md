### Added

- Every completed swarm tick pass writes a heartbeat with when it ended and when the host room, quota and ledger revision it decided on were last observed.
- `agentihooks swarm tick-watch`, a stale tick watcher apart from the tick, sends one inbox alert per stale episode to the front door master seat and every live agent seat with the evidence, and a resolved notice when a fresh pass lands. On a workstation it restarts the scheduler tick from the installed agentihooks and respawns an empty front door master. It runs as the `agentihooks-tick-watch` user service.
