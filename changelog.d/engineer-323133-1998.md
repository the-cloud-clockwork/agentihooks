### Added

- Every completed swarm tick pass writes a heartbeat with when it ended and when the host room, quota and ledger revision it decided on were last observed.
- The controller liveness probe fails when the tick it runs has completed no pass for ten minutes or decides on an input frozen ten minutes, so Kubernetes restarts the tick.
- `agentihooks swarm tick-watch`, a stale tick watcher apart from the tick, sends one inbox alert per stale episode to the front door master seat and every live agent seat with the evidence, a resolved notice when a fresh pass lands, and respawns an empty front door master on a workstation. It runs as the `agentihooks-tick-watch` user service and the chart's `tick-watch` Deployment.
