### Added

- Carry a hive launch's opening prompt, its sha256 digest and the task work folder seeds in the launch payload; the hive refuses a mismatched digest, materializes the seeds below its own home and launches with the carried prompt unchanged.
- Sync the work folder lines of each hive's hosted executions below its own hive key every heartbeat, so the published ledger workspace tails show progress and proof from remote hives; resume and recovery texts name the remote folder below the hive's home.

### Changed

- A hive refuses a launch payload that carries no opening prompt and digest, so deploy controllers before hives when upgrading.
