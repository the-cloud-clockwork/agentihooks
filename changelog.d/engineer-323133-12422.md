### Added

- The CI lab scheduler now feeds its shadow comparison live: the GitHub webhook receiver publishes each completed check run on `ci.lab.head.check_completed`, the scheduler hands each to the shadow recorder in delivery order, and a lab verdict that disagrees with GitHub Actions counts `ci_lab_verdict_mismatch_total` on the scheduler's metrics port. Lab side check runs count once the scheduler's environment names the lab App slug in `AGENTIHOOKS_LAB_APP`.
