### Added

- `SWARM_URL` points the ledger CLI, the swarm tick and the ledger hooks at a hosted Swarm ledger. With it set, or any non-local `AGENTIHOOKS_DEPLOYMENT`, they never start or restart a local ledger server.
- `SWARM_ACCESS_CLIENT_ID` and `SWARM_ACCESS_CLIENT_SECRET` add the Cloudflare service token headers to every ledger request, upload, event stream, proof ledger call and health probe, with the named user agent `agentihooks-swarm` that Cloudflare lets through.
- A client holding `SWARM_SECRET` derives its own agent token, and the swarm tick hands each agent it spawns its own token; neither the secret nor the tick's own token reaches a spawned agent.
