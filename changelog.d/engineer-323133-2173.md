### Added

- `agentihooks hive compare` lists every live hive's configuration (account tokens, env settings, bundle, profiles, rules, skills, MCP servers, dependencies and repos, named without values or host paths) against a base hive and prints each difference.

### Changed

- A headless hive never runs a master; with no UI hive live the master waits.

### Fixed

- A hive that holds an account token but never probes it, such as a worker pod, shows the account's real cap from the newest reading another hive published instead of zero.
