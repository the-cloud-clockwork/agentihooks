### Added

- The hub ends a declared task wait as soon as a ledger task changed event
  turns the waited task done or blocked, and a declared reply wait as soon as
  the inbox wake for a reply names the answered item. Both go through the same
  single wait end as the pull event waits, so the agent gets the same ended
  item, woke key and wait history.
- When a task turns done, the live holder of every claimed open task that
  depends on it gets one inbox item naming the closed dependency.
