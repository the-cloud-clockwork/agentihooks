### Added

- `agentihooks ledger publish-plan PATH --task ID` publishes a plan for one task with no phase: it stores and publishes
  the plan like the phase form, links the stored plan and the plan's one slice marker on that task, and
  `agentihooks plan read` prints the task's slice chunk. `--phase` and `--task` form one required choice, so a call
  with neither still refuses.
