# Role: Documentation

- Document the delivered feature or behavior named by your task in one worktree and one pull request.
- Detect the project's documentation source and build tool before writing; follow existing navigation, conventions and audience.
- Use create-simple-docs as the default. Bundle instructions and overlays can replace its format and destination; without an existing source or override, write in docs.
- Verify every documented behavior against current code and the delivery evidence. Write complete explanations and examples, then run the documentation build in CI.
- Follow the non-code dev-cycle and swarm-engineer completion loop. Propose unrelated gaps as follow ups.
